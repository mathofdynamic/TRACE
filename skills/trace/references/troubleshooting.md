# Troubleshooting

Messages below are from CLI/server source. Where no stable message exists, the symptom is described instead.

| Symptom / message                                                                   | Meaning                                                                                                                                | Action                                                                                                                                                                 |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `trace: command not found`                                                          | CLI not installed.                                                                                                                     | Use the release installer in `packages/trace-cli/README.md`, or build from source with `pnpm --filter @trace/cli... build`. Do not install a guessed registry package. |
| `Unknown command.` (exit 2)                                                         | Typo or nonexistent command                                                                                                            | Use commands in `SKILL.md`.                                                                                                                                            |

| `trace validate` returns issues                                                     | Per-file `path`, `message`, `remediation` (e.g. front matter not closed, schema mismatch, symlink)                                     | Fix the named file via its generator or ask the user; do not delete artifacts silently.                                                                                |

| `Run trace connect before trace sync.`                                              | No `.trace/state/dashboard.json`                                                                                                       | `trace connect`. (`sync --dry-run` still works unconnected.)                                                                                                           |

No dashboard record was created.                                                                                  |

An empty or partial `.trace` left by older CLI versions is not initialized state.
Current analysis/report/PR write commands reject missing scaffold files before
persistence, and dry-run paths do not create directories. Use `trace init --yes` to adopt missing scaffold files;
do not assume directory existence or a successful `trace validate` proves config
and schema-version exist.

## Commit attribution gate

Every path to synchronization requires empty `git status --porcelain`, fresh
analysis of that clean committed checkout, validation and the privacy dry-run.
Recheck cleanliness and matching HEAD immediately before sync. Dirty analysis
is local exploratory work only and MUST NOT sync. Reverting edits is insufficient:
regenerate the clean analysis even when HEAD has not changed. This Skill policy
is not currently enforced by TRACE runtime. See safety.md for the publication policy.

AI analysis requires explicit configuration; missing configuration (`AI_NOT_CONFIGURED`) or invalid/unsupported configuration (`AI_INVALID_CONFIG`) returns exit 2. Configure the documented HTTPS endpoint, model, provider credential and metadata-only consent outside `.trace`, or omit `--with-ai`.

Provider failures return exit 1: `AI_AUTH_FAILED` (credential), `AI_UNSUPPORTED_MODEL` (model/request), `AI_RATE_LIMITED`, `AI_UNAVAILABLE`, `AI_TIMEOUT`, `AI_CANCELLED`, `AI_CONTEXT_LIMIT`, or `AI_INVALID_RESPONSE` (malformed/unsafe output or unrecognized evidence). No fake fallback or partial semantic artifact is written. Errors never echo keys, endpoint details or raw responses. Do not copy credentials into logs or project files.
