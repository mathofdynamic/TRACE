# Troubleshooting

Messages below are from CLI/server source. Where no stable message exists, the symptom is described instead.

| Symptom / message                                                                   | Meaning                                                                                                                                | Action                                                                                                                                                          |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `trace: command not found`                                                          | CLI not installed. `@trace/cli` is a private workspace package.                                                                        | Tell the user to build it from the TRACE repo (`pnpm --filter @trace/cli... build`, binary `packages/trace-cli/dist/cli.js`). Do not install a guessed package. |
| `Unknown command.` (exit 2)                                                         | Typo or nonexistent command                                                                                                            | Use commands in `SKILL.md`.                                                                                                                                     |
| `.trace` missing / "TRACE directory does not exist."                                | Not initialized                                                                                                                        | `trace init --yes`.                                                                                                                                             |
| `TRACE is not initialized in this repository. Run \`trace init --yes\` first.`      | `connect` needs `config.yml` + `schema-version`                                                                                        | Init, then connect.                                                                                                                                             |
| `TRACE already exists; use --yes only to adopt without overwriting existing files.` | init on existing `.trace`                                                                                                              | Usually fine; `trace init --yes` adopts missing files.                                                                                                          |
| `trace validate` returns issues                                                     | Per-file `path`, `message`, `remediation` (e.g. front matter not closed, schema mismatch, symlink)                                     | Fix the named file via its generator or ask the user; do not delete artifacts silently.                                                                         |
| `Run trace login.` / `Run trace login before trace connect.`                        | No usable credential                                                                                                                   | `trace login` (human approval).                                                                                                                                 |
| `Device authorization expired. Run trace login again.`                              | Approval not completed in time                                                                                                         | Rerun login; user must approve.                                                                                                                                 |
| `remote.origin.url is not an unambiguous GitHub repository URL.`                    | Non-GitHub or malformed remote                                                                                                         | Ask the user to fix the remote; do not guess.                                                                                                                   |
| `<owner/repo> is not selected in this TRACE workspace.`                             | Repo not selected/granted                                                                                                              | User selects it in the dashboard / grants GitHub App; then `trace connect`.                                                                                     |
| `Repository identity is ambiguous.`                                                 | More than one match                                                                                                                    | Human decision; do not pick.                                                                                                                                    |
| `Run trace connect before trace sync.`                                              | No `.trace/state/dashboard.json`                                                                                                       | `trace connect`. (`sync --dry-run` still works unconnected.)                                                                                                    |
| `Run trace login for the server configured by trace connect.`                       | Credential server differs from binding                                                                                                 | `trace login` against the bound server (user decides any `--server`).                                                                                           |
| `Invalid or expired CLI credential.` / `CLI authentication required.` (401)         | Expired (30 days) or revoked device                                                                                                    | `trace login`. Synced data is not removed.                                                                                                                      |
| `TRACE dashboard is unavailable (...). Local .trace files are unchanged.`           | Network/cloud failure after 3 retries                                                                                                  | Retry later; local state is safe.                                                                                                                               |
| `Dashboard divergence requires review; no local files were changed.`                | Dashboard has a newer operation than this checkout acknowledged                                                                        | Stop. `trace sync status --json`; user decides about `--accept-dashboard-base`; then re-analyze and dry-run.                                                    |
| Sync rejected by server (previous exact manifest rejected)                          | Server refused the artifact set                                                                                                        | Read `excluded`/error and Request ID; correct the artifact or policy via its generator, then a new manifest. Do not retry blindly.                              |
| `excluded` reason `code snippets are disabled`                                      | Fence or code-like lines present                                                                                                       | Regenerate with the CLI; never hand-strip to bypass without telling the user.                                                                                   |
| `excluded`: `artifact exceeds 256 KiB` / `Sync exceeds 2 MiB` / >64 artifacts       | Size/count limits                                                                                                                      | Report to user; do not split or truncate artifacts by hand.                                                                                                     |
| `excluded`: `no dashboard projection`                                               | e.g. current `pr_brief`                                                                                                                | Expected; stays local.                                                                                                                                          |
| `Artifact already exists: <path>`                                                   | daily/weekly/pr write on existing file                                                                                                 | No overwrite flag exists. Ask before deleting; use the preview.                                                                                                 |
| `Use: trace analyze [changes] [--with-ai]`                                          | bad analyze args                                                                                                                       | Fix args.                                                                                                                                                       |
| Connected sync fails manifest validation on `git.branch`                            | Detached HEAD (`git branch --show-current` is empty; schema requires >=1 char). Inferred from schema; unconnected dry-run still works. | Ask user to check out a branch.                                                                                                                                 |
| Analysis failed                                                                     | Exception from `trace analyze`                                                                                                         | Read stderr; rerun; check `git`, repo state; report. No dashboard record was created.                                                                           |
| Dashboard "Needs refresh"                                                           | Remote HEAD != last synced head                                                                                                        | `lifecycle.md`: analyze -> dry-run -> sync.                                                                                                                     |
| "Freshness unavailable"                                                             | Remote HEAD unknown                                                                                                                    | Not fixable from CLI; wait/check GitHub App state.                                                                                                              |
| Local commit differs from remote                                                    | Unpushed or diverged                                                                                                                   | Do not sync just to match; user publishes; then refresh.                                                                                                        |
| "Computer revoked"                                                                  | Device revoked in dashboard                                                                                                            | `trace login` (human).                                                                                                                                          |
| `trace doctor` exit 1                                                               | git missing or `.trace` invalid                                                                                                        | Fix per output.                                                                                                                                                 |

An empty or partial `.trace` after analysis (including an empty root after dry-run)
is not initialized state. Use `trace init --yes` to adopt missing scaffold files;
do not assume directory existence or a successful `trace validate` proves config
and schema-version exist.

## Commit attribution gate

Every path to synchronization requires empty `git status --porcelain`, fresh
analysis of that clean committed checkout, validation and the privacy dry-run.
Recheck cleanliness and matching HEAD immediately before sync. Dirty analysis
is local exploratory work only and MUST NOT sync. Reverting edits is insufficient:
regenerate the clean analysis even when HEAD has not changed. This Skill policy
is not currently enforced by TRACE runtime. See safety.md for the publication policy.

`--with-ai` is not a configured real AI capability in this CLI release. Its
fixture/no-provider output must not be presented as model-backed intelligence;
check provenance and do not imply source was sent to a model.
